# 🚀 NEXUS — Мобильное приложение на React Native (Expo SDK 57)

Кроссплатформенное мобильное приложение киберпанк-сообщества разработчиков **NEXUS**, сверстанное на стеке **React Native / TypeScript** с полной поддержкой **Expo SDK 57**, **React 19** и **New Architecture (Fabric)**.

В проект перенесены **все 3 макета**:
1. **Главная лента (`FeedScreen`)** — перенос макета из первой лабораторной.
2. **Ветка обсуждения (`ThreadScreen`)** — детальный экран ветки с блоком кода и комментариями.
3. **Профиль автора (`ProfileScreen`)** — экран профиля Elena Rostova с протоколом кармы и постами.

---

## ⚡ Быстрый запуск в 1 клик (Windows)

В корне проекта создан файл **[`run.bat`](run.bat)**. Просто запустите его двойным щелчком мыши:

```text
======================================================================
               NEXUS — React Native Mobile Application
                  (Expo SDK 57 / React 19 / Metro)
======================================================================

  [1] Телефон: Expo Go через облачный туннель (Рекомендуется ⭐)
  [2] Телефон: Expo Go по локальной сети Wi-Fi
  [3] Компьютер: Мгновенный запуск в браузере (React Native Web)
  [4] Проверка зависимостей и сборки (Expo Doctor)
  [0] Выход
```

## 📱 Способы запуска на телефоне

### Вариант 1: Через Expo Go с туннелем (Рекомендуется ⭐)
Работает независимо от сетевых настроек, изоляции Wi-Fi на роутере, брандмауэра Windows и VPN-адаптеров (Radmin / Hamachi).

1. Установите на телефон бесплатное приложение **Expo Go**:
   - **Android:** [Google Play → Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - **iPhone:** [App Store → Expo Go](https://apps.apple.com/app/expo-go/id982107779)
2. Запустите в терминале:
   ```powershell
   npx expo start --tunnel -c
   ```
3. Отсканируйте появившийся QR-код:
   - **Android:** в приложении Expo Go нажмите **«Scan QR code»**.
   - **iOS:** наведите стандартную **камеру телефона** на QR-код и нажмите плашку *«Открыть в Expo Go»*.

---

### Вариант 2: Через локальную сеть Wi-Fi (LAN)
Если телефон и компьютер подключены к одному домашнему Wi-Fi:
```powershell
npx expo start -c
```
*(Если на ПК включен Radmin VPN, укажите реальный локальный IP: `$env:REACT_NATIVE_PACKAGER_HOSTNAME="192.168.100.128"; npx expo start`)*.

---

### Вариант 3: Просмотр на ПК в браузере (React Native Web)
Для мгновенного тестирования верстки на широком экране с симулятором рамки телефона:
```powershell
npm run dev
```
Откройте в браузере: `http://localhost:3000`.  
В верхней панели доступны кнопки переключения между всеми 3 экранами и тумблер рамки смартфона.

## 🧩 Описание экранов приложения

### 1. Главная лента — `FeedScreen.tsx`
- **Шапка:** Логотип `NEXUS`, круглые кнопки уведомлений и сообщений со светящимися индикаторами онлайна (`#00F5A0` и `#C084FC`), аватар профиля с неоновым кольцом.
- **Панель фильтров:** горизонтальный скролл пилюль (`⚡ В тренде`, `👥 Подписки`, `🌐 Все`, `📓 Технологии`).
- **Баннер трансляции:** `ТРАНСЛЯЦИЯ ПОДПРОСТРАНСТВА • УЗЕЛ #882` с пульсирующей точкой.
- **Пост 1 (`@kira_valkyri`):**
  - Терминальный блок `ЛОГ_ТЕЛЕМЕТРИИ` с метриками задержки.
  - Векторный график затухания задержки (`LatencyCurveSvg`, `-42% по сравнению с SOTA`) со светящейся точкой на конце.
  - Реакции (`+2.4k`, `342`, `89`, репост, закладка).  
  *Клик по карточке открывает экран ветки обсуждения.*
- **Пост 2 (`@zeno_flux`):** голографическое превью интерфейса `Nexus Engine v2.4` (120 FPS), активная фиолетовая закладка.
- **Баннер «Награда подпространства»:** задача по устранению состояния гонки памяти и кнопка `Обзор`.
- **Нижняя навигация:** плавающая панель с активной иконкой ленты, центральной кнопкой `+` (FAB) и аватаром профиля.

---

### 2. Ветка обсуждения — `ThreadScreen.tsx`
- **Шапка:** кнопка «Назад» (`←`), мини-логотип `Ветка обсуждения`, кнопка «Поделиться», аватар профиля.
- **Главный пост Kira Vance:**
  - Бейдж верификации, авторский заголовок *«Автономная субъектность против масштабированного вероятностного вывода»*.
  - Встроенный терминальный блок **`MESH_DISPATCHER.PY`** с цветными точками macOS, кнопкой копирования и подсветкой синтаксиса Python (`async def`, `await`, `speculative_v4`, `latency_budget_ms=1.4`).
  - Панель реакций: `↑ 4.2k ↓`, кнопка `Репост`, закладка, «Поделиться».
- **Древовидная ветка комментариев:**
  - Шапка с бейджем `582` и фильтрами `Лучшие` / `Новые`.
  - Комментарий 1: **Marx Cyber** (`@marx_cyber • 1ч назад`), реакция `↑ +428`, кнопка `Ответить`.
  - Комментарий 2: **Nova** (`@dev_nova • 42м назад`) с фиолетовой направляющей линией ветки.
  - Комментарий 3 (ответ автора): **Kira Vance** с мятным бейджем **`OP`** и мятной линией ветки.
- **Фиксированная нижняя панель ввода:** текстовое поле с плейсхолдером `Ответить @kira_valkyrie...`, смайлик, иконки вложений (изображение, `< >` код, график) и круглая мятная кнопка отправки.

---

### 3. Профиль пользователя — `ProfileScreen.tsx`
- **Герой профиля:** большой аватар **Elena Rostova** (`@elena_dev`) с неоновым кольцом и индикатором онлайна, кнопка `Редактировать` (с иконкой карандаша) и кнопка настроек (шестеренка).
- **Био:** верифицированный аккаунт фулстек AI-архитектора децентрализованных нейрофорумов.
- **Карточка «Протокол кармы NEXUS»:**
  - Бейдж `✨ Топ 1% авторов`, рейтинг `48,920 РЕП`.
  - 3 карточки под-метрик: `Апвоуты: 124.5k (+12%)`, `Решения: 86 (98.2%)`, `Влияние: Мастер (Ранг IV)`.
- **Счетчики:** `1,420` Подписки, `18.6k` Подписчики, `248` Ветки, `14` Значки.
- **Вкладки:** `Ветки` (активная с мятным подчеркиванием), `Ответы`, `Медиа`, `Оценки`, `Сохранено`.
- **Список публикаций:** пост по WebAudio API (`c/neural-net`) и пост по WebGL-шейдерам (`c/cyberpunk-dev`) с графическим вложением смартфона и ссылкой на GitHub.

## 📂 Структура проекта

```text
react-native-nexus/
├── assets/                          # Оригинальные графические ассеты (логотипы, аватары, превью)
├── src/
│   ├── theme/
│   │   └── colors.ts                # Цветовая палитра темы (неоновый мятный, фиолетовый, темные фоны)
│   ├── types.ts                     # TypeScript интерфейсы и типы
│   ├── components/
│   │   ├── SvgIcons.tsx             # Векторные SVG-иконки и SVG-график кривой затухания
│   │   ├── SvgWeb.tsx               # Кроссплатформенный SVG-мост для веб-версии
│   │   ├── Header.tsx               # Верхняя шапка приложения
│   │   ├── BottomNav.tsx            # Нижняя док-панель навигации
│   │   └── PhoneSimulator.tsx       # Реалистичная рамка смартфона с кнопками и Home Bar
│   └── screens/
│       ├── FeedScreen.tsx           # Экран 1: Главная лента постов
│       ├── ThreadScreen.tsx         # Экран 2: Ветка обсуждения и комментарии
│       └── ProfileScreen.tsx        # Экран 3: Профиль автора и протокол кармы
├── App.tsx                          # Корневой компонент с безопасной зоной и переключателем экранов
├── index.html                       # HTML-шаблон для браузерного предпросмотра
├── index.js                         # Точка входа для Expo (registerRootComponent)
├── index.web.js                     # Точка входа для React Native Web (AppRegistry)
├── babel.config.js                  # Конфигурация Babel с пресетом babel-preset-expo
├── app.json                         # Манифест Expo SDK 57
├── vite.config.js                   # Конфигурация Vite для мгновенного веб-запуска
├── run.bat                          # Скрипт быстрого запуска для Windows
└── package.json                     # Зависимости проекта
```
