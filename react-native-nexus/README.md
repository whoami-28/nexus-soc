# 🚀 NEXUS — Полноценное мобильное приложение на React Native с базой данных SQLite

Полнофункциональное кроссплатформенное мобильное приложение киберпанк-сообщества разработчиков **NEXUS**, реализованное на стеке **React Native / TypeScript** с полной поддержкой **Expo SDK 57**, **React 19** и нативной базы данных **SQLite (`expo-sqlite`)**.

---

## 💾 Архитектура базы данных SQLite

Вся информация хранится локально на устройстве в базе данных `nexus.db` через асинхронный API библиотеки `expo-sqlite`:

| Таблица | Описание | Основные поля |
| :--- | :--- | :--- |
| **`users`** | Профили разработчиков и авторов | `id`, `handle`, `name`, `avatar_key`, `bio`, `github_url`, `matrix_url`, `rep_score`, `network_rank` |
| **`posts`** | Публикации и сетевые релизы в ленте | `id`, `author_id`, `topic_tag`, `category`, `title`, `content`, `code_snippet`, `media_type`, `upvotes` |
| **`comments`** | Древовидные ветки комментариев | `id`, `post_id`, `author_id`, `parent_id`, `content`, `code_snippet`, `upvotes`, `depth` |
| **`user_interactions`** | Реакции пользователя и закладки | `id`, `user_id`, `target_type`, `target_id`, `vote_type`, `is_bookmarked` |
| **`notifications`** | Сетевые уведомления узла | `id`, `user_id`, `actor_id`, `type`, `title`, `body`, `target_post_id`, `is_read` |
| **`bounties`** | Награды и задачи подпространства | `id`, `title`, `reward_amount`, `description`, `difficulty`, `status` |

При первом запуске база данных автоматически инициализируется и наполняется начальным датасетом (пользователи Elena Rostova, Kira Vance, Zeno Flux, Marx Cyber, Nova; публикации с графиком затухания телеметрии, блок кода Python, спецификации шейдеров и ветки комментариев).

## ⚡ Ключевые функции мобильного приложения

1. **Создание публикаций (`CreatePostModal`)**:
   - Вызывается нажатием на центральную кнопку **`+` (FAB)** на нижней панели навигации.
   - Позволяет задать заголовок, текст, выбрать тег спецификации (`#КВАНТОВЫЙ_СИНТЕЗ`, `#ВЕБ-ГПУ`, `#СЕТИ_AI`, `#АРХИТЕКТУРА`), прикрепить блок кода с именем файла или интерактивный график затухания задержки SOTA.
   - Мгновенная запись в SQLite с обновлением ленты.

2. **Динамическая лента (`FeedScreen`)**:
   - Загрузка публикаций напрямую из базы данных.
   - Фильтрация по категориям (`⚡ В тренде`, `👥 Подписки`, `🌐 Все`, `📓 Технологии`).
   - Живой поиск по заголовкам, описанию и тегам.
   - Интерактивные лайки / дизлайки с мгновенным пересчетом и сохранением в SQLite.
   - Добавление постов в избранное (закладки).
   - Автор может удалять свои публикации через меню `...`.
   - Тап по любой карточке открывает ветку обсуждения именно этой публикации.

3. **Интерактивная ветка обсуждения (`ThreadScreen`)**:
   - Открывает выбранный пост из ленты.
   - Отображает древовидные комментарии из SQLite с цветовой индикацией уровней вложенности (зеленая линия для автора OP, фиолетовая для других участников).
   - Полноценная нижняя панель ввода: позволяет отвечать на пост или конкретный комментарий с мгновенным сохранением в БД.
   - Сортировка комментариев: `Лучшие` (по лайкам) и `Новые` (по дате).
   - Интерактивное копирование блоков кода терминала.

4. **Профиль автора и Протокол Кармы (`ProfileScreen`)**:
   - Отображение текущего пользователя (Elena Rostova, `@elena_dev`).
   - Карточка Протокола Кармы: счетчик `48,920 REP` и сетка из 4 метрик (`ПРОВЕРЕНО`, `НАГРАДЫ`, `ВКЛАДЫ`, `РАНГ СЕТИ`).
   - Динамический пересчет кармы автора при получении лайков и наград.
   - Вкладки:
     - **«Трансляции»**: посты, опубликованные текущим пользователем.
     - **«Закладки»**: посты, сохраненные пользователем в SQLite.
   - Кнопка **«Редактировать»**: модальное окно (`EditProfileModal`) для изменения имени, био, статуса и ссылок с сохранением в БД.
   - Кнопка **«Настройки»**: сброс базы данных SQLite к исходному состоянию для повторного тестирования.

5. **Центр сетевых уведомлений (`NotificationsModal`)**:
   - Открывается по клику на колокольчик в шапке.
   - Показывает счетчик непрочитанных событий на иконке.
   - Список уведомлений об ответах, апвоутах и наградах.
   - Кнопка «Прочитать все» и быстрый переход в ветку обсуждения по тапу на уведомление.

6. **WebView-оболочка (Лабораторная работа №6)**:
   - Сохранена в верхней панели переключения экранов (`🌐 WebView (ЛР6)`).
   - Загружает веб-приложение с GitHub Pages: [https://whoami-28.github.io/nexus-soc/](https://whoami-28.github.io/nexus-soc/).

## 📱 Быстрый запуск на телефоне

Запустите **[`run.bat`](run.bat)** двойным щелчком мыши:

```text
======================================================================
           NEXUS — React Native Mobile App (SQLite Engine)
              (Expo SDK 57 / React 19 / expo-sqlite / Metro)
======================================================================

  Выберите вариант запуска для смартфона:

  [1] Телефон: Expo Go через облачный туннель (Рекомендуется ⭐)
      - Работает на любом телефоне (Android / iPhone)
      - Не зависит от Wi-Fi роутера, Radmin VPN и брандмауэра Windows

  [2] Телефон: Expo Go по локальной сети Wi-Fi
      - Телефон и компьютер должны быть в одной сети Wi-Fi

  [3] Проверка TypeScript и сборки Metro (Expo Doctor & TSC)
      - Проверка компиляции и валидация модулей

  [0] Выход
======================================================================
```

1. Выберите **`1`** и нажмите **Enter**.
2. Отсканируйте появившийся QR-код в приложении **Expo Go** на телефоне (Android — через кнопку «Scan QR code» в Expo Go, iPhone — стандартной камерой).
3. Приложение откроется на смартфоне с подключенной базой данных SQLite!
