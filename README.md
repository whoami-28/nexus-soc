# 🚀 NEXUS — Мобильное приложение на React Native (Expo SDK 57)

Кроссплатформенное мобильное приложение киберпанк-сообщества разработчиков **NEXUS**, сверстанное на стеке **React Native / TypeScript** с полной поддержкой **Expo SDK 57**, **React 19** и **New Architecture (Fabric)**.

В проект перенесены **все 3 макета**:
1. **Главная лента (`FeedScreen`)** — перенос макета из первой лабораторной.
2. **Ветка обсуждения (`ThreadScreen`)** — детальный экран ветки с блоком кода и комментариями.
3. **Профиль автора (`ProfileScreen`)** — экран профиля Elena Rostova с протоколом кармы и постами.

---

## ⚡ Быстрый запуск в 1 клик (Windows)

В корне проекта создан файл **[`run.bat`](run.bat)**. Просто запустите его двойным щелчком мыши:

```text
======================================================================
               NEXUS — React Native Mobile Application
                  (Expo SDK 57 / React 19 / Metro)
======================================================================

  [1] Телефон: Expo Go через облачный туннель (Рекомендуется ⭐)
  [2] Телефон: Expo Go по локальной сети Wi-Fi
  [3] Компьютер: Мгновенный запуск в браузере (React Native Web)
  [4] Проверка зависимостей и сборки (Expo Doctor)
  [0] Выход
```

## 📱 Способы запуска на телефоне

### Вариант 1: Через Expo Go с туннелем (Рекомендуется ⭐)
Работает независимо от сетевых настроек, изоляции Wi-Fi на роутере, брандмауэра Windows и VPN-адаптеров (Radmin / Hamachi).

1. Установите на телефон бесплатное приложение **Expo Go**:
   - **Android:** [Google Play → Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - **iPhone:** [App Store → Expo Go](https://apps.apple.com/app/expo-go/id982107779)
2. Запустите в терминале:
   ```powershell
   cd d:\01_Temp\Projects\Mobilki\react-native-nexus
   npx expo start --tunnel -c
   ```
3. Отсканируйте появившийся QR-код:
   - **Android:** в приложении Expo Go нажмите **«Scan QR code»**.
   - **iOS:** наведите стандартную **камеру телефона** на QR-код и нажмите плашку *«Открыть в Expo Go»*.

---

### Вариант 2: Через локальную сеть Wi-Fi (LAN)
Если телефон и компьютер подключены к одному домашнему Wi-Fi:
```powershell
cd d:\01_Temp\Projects\Mobilki\react-native-nexus
npx expo start -c
```
*(Если на ПК включен Radmin VPN, укажите реальный локальный IP: `$env:REACT_NATIVE_PACKAGER_HOSTNAME="192.168.100.128"; npx expo start`)*.

---

### Вариант 3: Просмотр на ПК в браузере (React Native Web)
Для мгновенного тестирования верстки на широком экране с симулятором рамки телефона:
```powershell
cd d:\01_Temp\Projects\Mobilki\react-native-nexus
npm run dev
```
Откройте в браузере: `http://localhost:3000`.  
В верхней панели доступны кнопки переключения между всеми 3 экранами и тумблер рамки смартфона.
